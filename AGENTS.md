# AGENTS.md

Презентации (Slidev) по курсу «Распределённое программирование».

## Правила

- **Не читать PNG-файлы** при проверке слайдов. Проверять правки по исходникам (`.md`, `.vue`), а не по отрендеренным картинкам.
- **Устоявшиеся термины — на английском.** Например: saga, choreography, orchestration, compensating transaction, idempotency, outbox, event, message broker. Не переводить их на русский и не транслитерировать.
  - Исключения (в тексте слайдов, не на диаграммах): payment provider → «платёжная система», payment authorization → «проверка возможности оплаты».
- **Диаграммы и схемы: компоненты — на английском, действия — на русском.**
  - Названия компонентов и сервисов, имена Activities/состояний, API-вызовы и устоявшиеся термины пишутся по-английски (например, `Order Service`, `Payment Service`, `Message Broker`, `ReserveInventory`, `POST /charge`, `Workflow Task`).
  - Подписи действий — сообщения, подписи стрелок, заметки, шаги-действия — пишутся по-русски (например, «Запланировать ChargePayment», «Результат или ошибка»).
