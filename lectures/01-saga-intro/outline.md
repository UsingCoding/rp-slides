# Лекция 1. Saga: распределённые бизнес-процессы

90 минут, 60 слайдов с обложкой, планом и разделителями. Русский язык; кодовые примеры на Go. Точка входа — `01-saga-intro.md`. Заметки преподавателя встроены в HTML-комментарии каждого слайда: время, пояснения, вопросы и ожидаемые ответы. Обложка и план показываются до начала отсчёта; обсуждения включены в тайминг.

## Единый контракт примера

Order создаёт `Pending`; Inventory резервирует товар; Payment **авторизует** сумму; Delivery бронирует доставку; Order фиксирует `Confirmed`. Capture, физическая отправка и исполнение подтверждённого заказа находятся за границей этой Saga.

- `PaymentFailed` означает достоверный отказ без авторизации. Компенсация — `ReleaseInventory`.
- `DeliveryBookingFailed` означает достоверный отказ без бронирования. Компенсации — `VoidAuthorization`, затем `ReleaseInventory`.
- `Cancelled` допустим только после подтверждения необходимых компенсаций.
- Timeout означает неизвестный исход. Сначала сверка либо безопасный повтор с тем же ключом; поздний успех учитывается и при выбранной отмене.
- `VoidAuthorization` не заменяем на refund: в этом примере списания не было.

## Go-примеры

На слайде 37 — чистая функция двух переходов автомата: подтверждённый отказ и неизвестный исход. Это явно ограниченный учебный фрагмент, не полноценный движок процессов. На слайде 49 — тип команды авторизации со стабильным ключом и суммой в минимальных денежных единицах. Сохранение состояния, таблица исходящих сообщений и взаимодействие с реальным платёжным API объясняются отдельно; они не подменены ненадёжной цепочкой вызовов в памяти. Термины на слайдах — на английском: имена сервисов, команд, событий и состояний на схемах совпадают с контрактом выше и с Go-кодом (`Order`, `ReserveInventory`, `PaymentFailed`, `Pending`), технические термины в тексте (`commit`, `timeout`, `idempotency key`, `compensation`, `outbox`) не переводятся. Заметки преподавателя — на русском.

## Запуск

Из корня проекта:

- `mise exec -- pnpm install --frozen-lockfile` — зависимости.
- `mise exec -- pnpm dev:01` — просмотр лекции.
- В интерфейсе Slidev открыть **Presenter Mode** для заметок.
- `mise exec -- pnpm build:01` — статическая сборка в `dist/01-saga-intro/`, базовый URL `/01-saga-intro/`.
- `mise exec -- pnpm export:01:pdf` — экспорт PDF существующей командой проекта.
